# Impressora Delivery do Sertão

Instalador do aplicativo que imprime automaticamente os pedidos do **Delivery do Sertão** na impressora térmica da loja (Windows).

👉 **Baixe a versão mais recente em [Releases](../../releases/latest)** (arquivo `Impressora-Delivery-do-Sertao-Setup-x.y.z.exe`).

Depois de instalado, o aplicativo se atualiza sozinho.
